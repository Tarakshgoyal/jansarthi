# Jansarthi Android releases

Client APKs in this directory are signed standalone builds that connect to the
production API. Send the APK file itself to the client; no Expo or developer
software is required.

## Installation

1. Download `Jansarthi-Android-1.0.2.apk` on the Android phone.
2. Open the downloaded file and allow installation from that source if Android asks.
3. Tap **Install**, then open **Jansarthi**.
4. Allow location and camera access when prompted so reports can include their
   location and photos.

The file must not be renamed to `.zip` or extracted. Future APK updates must be
built with the same EAS Android signing credential.
